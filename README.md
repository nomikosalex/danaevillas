# Danae Villas — Hotel & Villa Website

Marketing website for Danae Villas, a hotel and villa property in Santorini, Greece.

Built as a freelance project — worked directly with the owner to turn loose requirements into a shipped, responsive site on their timeline.

## Stack

- **Framework:** Next.js (App Router), TypeScript
- **Styling:** Tailwind CSS
- **Hosting:** Netlify

## Features

- Fully responsive design optimised for mobile (most visitors are tourists browsing on phones)
- SEO-ready with meta tags and structured markup
- Fast load times via Next.js static generation and image optimisation
